# Security Policy

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature for this repository if it
is available. Otherwise, contact the repository maintainer through a private
GitHub channel and include:

- A concise description and impact
- Reproduction steps or a proof of concept
- Affected files, versions, and environment
- Any suggested mitigation

Please allow reasonable time for investigation and remediation before public
 disclosure. Do not include real API keys, personal data, or production secrets
in reports.

## Scope

This is a research prototype. The policy does not imply that the application is
production-hardened or that a formal security response SLA exists.
